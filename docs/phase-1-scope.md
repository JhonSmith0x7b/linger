# Linger 一期功能与架构共识

更新日期：2026-11-10。以下为一期设计共识。已建立 Tauri 首版实现，具体完成范围、启动方式与尚待实测的项目见 [README](../README.md)。技术选型及参数可在验证后调整。

## 产品范围

开发独立的 AI 陪伴项目。N.E.K.O 仅作参考，源码位于 `references/N.E.K.O/`；记忆机制参考 NousResearch Hermes Agent 的少量常驻记忆、工具维护和历史按需检索。

首发同时支持 macOS 和 Windows：日常开发在 macOS，实际使用主要在 Windows。技术选型调研见 [跨平台技术架构调研](technical-architecture-research.md)，当前采用 Tauri 2 + React/TypeScript + Rust + SQLite；Windows 仍待真实设备验证。

一期核心是主动观察屏幕、人格化陪伴、全局按键语音、截图与搜索工具、明确偏好记忆。不做虚拟形象、口型和动作；声纹、唤醒词、音色克隆、电脑操作暂不纳入一期。

## 陪伴与输入

- 陪伴持续运行，麦克风仅在用户按键时提交声音；停止录音不停止观察和主动搭话。
- 默认按住全局快捷键录音，松开提交 ASR 最终转写；悬浮工具栏独立语音按钮点击开始、再次点击停止发送。按下时立即停止当前播报，并取消或丢弃旧回复及迟到音频。
- 用户沉默是正常状态。AI 可以自然交流、自言自语、延续话题或暂时安静，不催促回应，也不因连续未回应就自动停止陪伴。
- 截图与发言分开调度。一次观察可以不说话；提供陪伴频率和临时勿扰设置。
- 用户输入优先于后台主动发言；两者共享人格、有效记忆和会话状态。

## 对话与工具

暂定主链路：按键录音 → ASR → 支持图片和工具的对话模型 → 流式 TTS → 播放。

TTS 一期暂定使用 `gpt-4o-mini-tts`，调用 `/v1/audio/speech`，不提前引入 Realtime 语音输出。设置支持音色 `voice`、风格指令 `instructions`、语速 `speed`（0.25–4.0，默认 1.0），以及高级选项中的输出格式 `response_format`；本地播放音量单独设置。提供试听与配置持久化，参数修改从下一次合成请求生效。保留简单的语音服务接口供未来替换；已知模型退役不改变当前选择。

一期模型边界已明确：所有模型推理均使用云端 API，以 OpenAI 官方 API 为开发与兼容基准，包括语音识别、对话／视觉、摘要与记忆提取、语音生成，以及需要时的向量化。默认直连官方，也支持用户配置局域网 NewAPI 中转的 Base URL，不部署本地模型。各用途独立选择能力匹配的官方模型；模型可配置不代表所有模型都能用于任意用途。本地继续负责采集、播放、调度、工具执行、SQLite 存储和检索。

不做账号系统，用户自带 API Key。提供全局 Base URL（默认 `https://api.openai.com/v1`）和 API Key 设置，各模型用途默认共用连接配置，模型 ID 可编辑以支持中转映射。Key 存系统凭据存储，不进入普通配置或日志；切换地址时明确该地址使用的 Key。允许用户主动配置局域网 HTTP 地址。开发与基线验证使用官方服务，NewAPI 的 Responses、图片、工具、搜索及语音参数透传另做集成验证，不预设完全兼容；不支持的能力明确报错，不静默切换端点或服务。

| 工具 | 行为约定 |
| --- | --- |
| 截图 | 立即获取授权窗口或区域的新图，返回时间与来源，并确保图片进入模型请求；不以旧图冒充新图 |
| 搜索 | 直接供对话模型调用，返回内容及来源链接 |
| 记忆维护 | 新增、修改、删除明确记忆；持久化成功后确认，并立即对当前会话生效 |
| 历史检索 | 按内容和时间查原始记录，必要时展开上下文 |

定时观察、用户提问和截图工具共用采集能力。截图绑定对应轮次；窗口失效时不擅自扩大为全桌面。

## 频率与上下文成本

| 参数 | 暂定值 |
| --- | --- |
| 自动观察 | 默认每 2 分钟，可选 1、3、5 分钟 |
| 主动观察文本输入 | 最多 6,000 tokens，与普通聊天共享历史和记忆组装方式 |
| 主动输出 | 生成上限 2048 tokens（含推理）；按话题自然表达，允许不发言 |
| 按键对话文本输入 | 通常不超过 6,000 tokens |
| 按键对话输出 | 生成上限 4096 tokens（含推理）；不限制句数，按话题与用户需要展开 |
| 图片 | 单次通常 1 张，图片用量另计 |

文本预算包含提示词、工具定义、记忆、历史与工具结果。主动观察只带精简人格、有效偏好、当前活动、近期话题和相关用户指令，不携带整段历史。

一次主动请求尽量同时完成看图、更新短期状态和决定是否发言。本地画面去重可跳过无变化的视觉请求；用户要求“现在看一下”立即截图，不受周期与去重限制。无新画面时可按陪伴节奏发起短文本自语，但不能假装看到了新画面。

未发言的观察不记作聊天轮次，只更新短期状态；实际发言进入聊天记录，重要观察可记为事件。原始截图默认不长期保存。

**不做每日后台调用／费用预算，也不做接近预算上限时自动降频。** 成本通过固定频率、上下文限制、画面去重和批量记忆整理控制。

## 记忆结构

| 层次 | 内容与使用方式 |
| --- | --- |
| 长期记忆 | 用户偏好、明确交代的事情、长期关注点；少量核心条目常驻，其余按需读取 |
| 当前陪伴状态 | 当前活动、观察来源、临时关注点、近期话题；即时更新，按范围和有效期失效 |
| 历史记录 | 用户发言、AI 发言、工具结果、关键事件；保留角色、时间和来源，按需检索 |
| 独立人格配置 | 性格、表达方式和陪伴规则；不由普通记忆提取自行改写 |

暂定本地 SQLite 为唯一持久数据源，可导出 Markdown；数据库组织与技术栈在下一步细化。记忆条目记录 ID、内容、类别、适用范围、来源消息、更新时间和有效期。提供查看、修改和删除入口。

观察范围与关注说明分开保存：前者是实际窗口或框选区域，由采集器执行；后者是“重点看任务提示”等语义偏好。临时要求覆盖长期默认值，到期恢复，不覆盖掉原长期设置。

记忆修改后下一轮立即生效。长会话通过近期摘要和有限最近对话维持连续性，旧原文按需检索。区分用户事实、AI 独白和屏幕推测，不能把 AI 反复自述当成用户确认的偏好。修改或遗忘后，旧摘要和检索结果不能重新激活失效偏好。

## 记忆写入与整理

- 聊天记录：每次用户发言和 AI 实际发言后立即保存，无需额外模型调用。
- 明确的记住、修改或忘记要求：当前轮通过工具执行，不等批次；通常沿用当前对话的工具调用。
- 普通聊天：批量整理摘要与有价值的候选记忆，异步执行，不阻塞交互。

自动整理只处理新增内容，以下任一条件触发：

1. 累计 10 轮用户参与的对话。
2. 距上次整理 30 分钟，且存在尚未整理的用户发言。
3. 待整理文本先达到约 4,000 tokens，提前分批处理。

一轮指用户一次输入及对应 AI 回应；截图、工具调用和主动自语不单独计轮次。整理完成后重置计数，只消费已处理范围。纯后台观察或自语不单独触发用户长期记忆提取。

每批更新短期摘要，并选择值得保留的用户信息；无新信息则不增加长期记忆。活动变化直接更新短期状态，近期自语用固定长度列表防重复，无需再单独调用模型整理。

## 首版交互补充（2026-11-10）

- API 连接提供模型列表读取：填写 Key 后可直接读取，也会在保存连接后自动读取；各用途使用可搜索的下拉列表，保留中转模型别名，不再要求手工输入模型 ID。列表读取失败明确显示原因；地址或 Key 变化后旧结果失效。
- 人格以角色卡呈现：静态二次元插画、性格标签、外在气质与内在性格说明、可编辑人格文本。当前预设为凉宫春日、雪之下雪乃、峰不二子，并保留原有自定义角色。每张卡的编辑内容独立保存；保存选择后影响后续请求，不清空历史和记忆，声音随角色的整套配置生效。图片用于界面展示，不是虚拟形象渲染，也不作为对话请求图片发送。

- 快捷键支持实际按键录入；录入期间临时释放原全局快捷键，完成、取消、失焦或超时后恢复，保存时验证新组合键是否冲突。
- 角色卡独立保存音色、声音 instructions 与语速，保存角色选择时整套应用；移除独立声音页和覆盖选项。试听直接使用未保存的声音草稿。音量放在主界面，TTS 模型与输出格式放在连接设置中，均不随角色切换。旧版本实际生效的声音配置自动迁移到当前角色。

### 透明陪伴入口

- 常驻为透明无边框的 48px 陪伴球，收起原生窗口 96×56（包括球旁常驻的翻译快捷按钮）；不常驻大块工具面板。靠近显示工具，按需展开翻译、近期对话和更多操作，Esc 收起并清空翻译与聊天草稿。
- 空闲绿、录音红、转写黄、思考紫、播报蓝，错误橙色提示；录音外圈跟随输入音量，定时观察短暂扩散动画，支持减少动画偏好。
- 小球只负责点击打开聊天和拖动，不再长按录音；语音使用独立按钮。透明间隙使用原生鼠标穿透，展开靠边时限制在屏幕工作区。自动反馈不主动请求焦点。
- 翻译使用独立模型和配置的目标语言，只发送本次原文，不写聊天或记忆、不播报，译文可复制。

- 悬浮层启用未激活窗口的首次点击；原生鼠标命中检测补发悬停状态，恢复鼠标交互时不依赖 WebView 补发 pointerenter。悬停仅展开工具，不激活窗口或抢键盘焦点。

- 翻译快捷按钮常驻球旁，点击后显式激活悬浮窗口并聚焦输入；Enter 提交、Shift+Enter 换行，中文输入法选词回车不提交。复制译文按钮固定在卡片底部。

- 悬浮窗口失去焦点立即收回陪伴球及翻译快捷按钮，清空翻译草稿与结果；已提交翻译可在后台自动复制，但不重新填回面板、展开或抢焦点。

- 单击陪伴球展开最近对话及文字输入，自动聚焦；Enter 发送、Shift+Enter 换行，输入法确认不提交。窗口失焦收起且清空聊天输入（翻译原文与译文同样清空）。读屏陪伴开启时显示常驻青绿色内环，不覆盖录音/思考/播报状态色。
